# Evelyn Gutierrez Photography

A photography portfolio website showcasing selected photo and video work, with dedicated gallery and contact pages.

## Highlights

- Editorial landing page and image-led portfolio gallery
- Responsive layout for desktop and mobile
- Contact page for booking inquiries
- Custom domain: [evelyngutierrez.com](https://www.evelyngutierrez.com)
- Deployed with GitHub Pages

## Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages

## Run Locally

```bash
npm install
npm start
```

Open the local URL printed by `serve` (usually `http://localhost:3000`).
